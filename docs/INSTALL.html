Инструкция по установке
темы FastCloud

Тема разработана для Paymenter v1.5.2 (Laravel 12 + Livewire 3). Документ описывает полный процесс установки: копирование файлов, сборку ассетов, настройку расширений и заполнение базы данных.

1Системные требования

КомпонентВерсияПримечание

PHP8.3+
Node.js18+Для сборки Vite
npm9+
БДMySQL 8 / MariaDB 10.6+

2Копирование файлов

Скопируй следующие папки и файлы из репозитория в соответствующие места установки Paymenter:

Откуда (репозиторий)Куда (Paymenter)
paymenter/themes/fastcloud/ themes/fastcloud/
paymenter/public/fastcloud/ public/fastcloud/
paymenter/extensions/Others/CreditsPlus/ extensions/Others/CreditsPlus/
paymenter/lang/ru/ lang/ru/ (заменить)
paymenter/lang/ru.json lang/ru.json
⚠️

При обновлении Paymenter в будущем — папки lang/ru/ могут быть перезаписаны стандартными. Храни резервную копию.

3Сборка CSS/JS

Тема использует Tailwind CSS v4 через Vite. Ассеты нужно собрать после установки.

# Перейди в корень Paymenter
cd /path/to/paymenter

# Установи зависимости (если ещё не)
npm install

# Сборка для продакшена
npm run build

# ИЛИ dev-режим с hot reload
npm run dev
ℹ️

Файлы public/fastcloud/marketing.css и public/fastcloud/marketing.js — статические, Vite их не трогает. Они копируются как есть.

После сборки сбрось кеш шаблонов:

php artisan view:clear
php artisan cache:clear

4Настройка .env

Обязательные значения в .env:

# Название сайта (отображается в <title>)
APP_NAME="FastCloud"

# Реальный URL сайта (используется для asset(), route() и почтовых ссылок)
APP_URL=https://fast-cloud.uk

# Язык интерфейса
APP_LOCALE=ru
APP_FALLBACK_LOCALE=en

# Почта — нужна для сброса пароля и уведомлений
MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=noreply@fast-cloud.uk
MAIL_PASSWORD=your_password
MAIL_FROM_ADDRESS=noreply@fast-cloud.uk
MAIL_FROM_NAME="FastCloud"
⚠️

APP_URL должен совпадать с реальным доменом. Неправильный URL сломает favicon, ссылки в письмах и OAuth-редиректы.

5Активация темы в админке

  1. Войди в админ-панель

    Перейди на /admin и войди под администратором.

  2. Открой настройки внешнего вида

    Settings → Appearance (или аналогичный раздел в твоей версии Paymenter).

  3. Выбери тему fastcloud

    В поле Theme выбери fastcloud и сохрани.

  4. Установи логотип

    Загрузи логотип через поле Logo. Тема поддерживает SVG и PNG. Рекомендуемый формат: SVG, прозрачный фон.

  5. Настрой цвета темы

    В настройках темы (см. раздел «Настройки темы») оставь значения по умолчанию — тема использует собственные CSS-переменные и не зависит от цветов Paymenter, кроме accent-цвета.

6Расширение CreditsPlus

CreditsPlus добавляет отображение баланса в навигацию для авторизованных пользователей и переопределяет компонент навигации когда пользователь залогинен.

Установка

  1. Файлы уже скопированы

    Если выполнил шаг 2, папка extensions/Others/CreditsPlus/ уже на месте.

  2. Включи расширение в админке

    Admin → Extensions → Others → CreditsPlus → Enable.

Как работает

Расширение регистрирует View Composer на components.navigation.index. Логика:

  • Пользователь не авторизован → используется навигация из темы (стандартно)
  • Пользователь авторизован → CreditsPlus подменяет путь к шаблону навигации на свой
  • В навигации появляется кликабельный баланс, ведущий на /account/credits
  • В мобильном меню — аватар + имя + выдвижная панель со ссылками
💡

Если нужно изменить навигацию (ссылки, логика), правки нужно вносить в два файла одновременно:
themes/fastcloud/views/components/navigation/index.blade.php (для незалогиненных)
extensions/Others/CreditsPlus/resources/views/components/navigation/index.blade.php (для залогиненных)

7Валюта

Тема использует рубли как основную валюту. Создай валюту в админке:

  1. Admin → Currencies → Create

  2. Заполни поля

    Code: RUB
    Prefix: оставь пустым
    Suffix: ₽ (с пробелом перед знаком)
    Default: включи

ℹ️

Тема ищет валюту с кодом RUB для отображения баланса в навигации. Если код будет другим — баланс не покажется корректно.

8Категории — Локации

В теме каждая top-level категория (без родителя) = одна локация на странице тарифов. Кнопки локаций на /pricing генерируются автоматически из категорий.

Создание категории

Admin → Categories → Create

ПолеПримерВажно

Порядок кнопок локаций на странице тарифов = порядок категорий по id (по возрастанию). Создавай в нужном порядке.

Product Settings — характеристики сервера

На странице конфигурации и в карточке тарифа отображаются характеристики. Они задаются через Product Settings (не Config Options). Ключи строго фиксированы:

Ключ (key)Пример значенияГде отображается
cpu4«4 vCPU» на карточке и в конфигураторе
ram8«8 GB RAM»
nvme80«80 GB NVMe»
trafficБезлимит«Безлимит трафик»
⚠️

Ключи чувствительны к регистру. Только строчные: cpu, ram, nvme, traffic. Если ключ не найден — показывается «—».

10Config Options — параметры при заказе

Поле «Название сервера» обязательно

Тема автоматически находит первый Config Option с типом text и использует его как поле имени сервера. Без него поле имени не появится.

Поле «Операционная система» опционально

ПолеЗначение

Дополнительные услуги (аддоны) опционально

Аддоны — Config Options с типом checkbox. Отображаются в секции «Дополнительные услуги».

ПолеЗначение
Typecheckbox
NameAnti-DDoS 10 Gbps

💡

Цена аддона в корзине считается динамически: при смене периода оплаты цена аддона пересчитывается. Убедись что для каждого аддона заданы цены для каждого доступного периода (1 мес, 3 мес, 6 мес, 12 мес).

11Планы и цены

Каждый продукт может иметь несколько планов (периодов оплаты). Тема распознаёт следующие периоды:

Billing PeriodBilling UnitКлюч в темеОтображение
1monthmonthly1 месяц
3monthquarterly3 месяца
6monthbiannual6 месяцев
12monthannual12 месяцев
⚠️

Другие периоды (например, 2 мес, 24 мес) тема игнорирует — план не попадёт на страницу тарифов.

Скидки на длинные периоды

Скидка считается автоматически: тема берёт цену 1-месячного плана и сравнивает с ценой за месяц при более длинном периоде. Если выходит дешевле — показывается бейдж −N%. Для этого обязательно должен существовать план на 1 месяц.

Настройка цен

  1. Создай план

    Product → Plans → Add Plan. Укажи Billing Period и Unit.

  2. Добавь цену

    В плане → Prices → Add Price. Выбери валюту RUB, укажи цену.

  3. Повтори для каждого периода

    1 мес, 3 мес, 6 мес, 12 мес.

13Задачи программисту dev

Следующие вещи выходят за рамки темы и требуют правок в PHP-коде Paymenter:

1. Заголовки страниц (SEO)

Маркетинговые страницы (/pricing, /locations и др.) не передают $title в лейаут — все страницы показывают просто «FastCloud». Нужно добавить атрибут #[Title] к соответствующим Livewire-компонентам: 

// app/Livewire/Marketing/Pricing.php
use Livewire\Attributes\Title;

#[Title('Тарифы')]
class Pricing extends Component { ... }

Аналогично для: Locations, Contacts, Home, Offer, Privacy, Sla.

2. OG-теги для соцсетей

Добавить $description и $image слоты в лейаут каждой маркетинговой страницы для корректного превью в соцсетях. Лейаут layouts/app.blade.php уже поддерживает эти слоты.

3. «Популярный» тариф

Сейчас featured-продукт определяется хардкодом в app/Livewire/Marketing/Pricing.php: 

'featured' => $product->name === 'Pro',

Рекомендуется заменить на поле в Product Settings (например, ключ featured = 1), или использовать отдельное поле продукта.

4. Уведомления об ошибках на русском

Некоторые сообщения Paymenter передаются хардкодом на английском (например, в app/Livewire/Cart.php). В теме реализован JS-словарь переводов, но при добавлении новых уведомлений нужно пополнять словарь в themes/fastcloud/views/components/notification.blade.php.

5. Сервер приложений

Для продакшена рекомендуется настроить supervisor для очереди задач: 

php artisan queue:work --daemon
