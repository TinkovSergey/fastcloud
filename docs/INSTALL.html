Инструкция по установке
темы FastCloud

Тема разработана для Paymenter v1.5.2 (Laravel 12 + Livewire 3). Документ описывает полный процесс установки: копирование файлов, сборку ассетов, настройку расширений и заполнение базы данных.

КомпонентВерсияПримечание

PHP8.3+
Node.js18+Для сборки Vite
npm9+
БДMySQL 8 / MariaDB 10.6+

2Копирование файлов

Скопируй следующие папки и файлы из репозитория в соответствующие места установки Paymenter:

Откуда (репозиторий)Куда (Paymenter)
paymenter/themes/fastcloud/ themes/fastcloud/
paymenter/public/fastcloud/ public/fastcloud/
paymenter/extensions/Others/CreditsPlus/ extensions/Others/CreditsPlus/
paymenter/lang/ru/ lang/ru/ (заменить)
paymenter/lang/ru.json lang/ru.json
⚠️

При обновлении Paymenter в будущем — папки lang/ru/ могут быть перезаписаны стандартными. Храни резервную копию.

3Сборка CSS/JS

Тема использует Tailwind CSS v4 через Vite. Ассеты нужно собрать после установки.

# Перейди в корень Paymenter
cd /path/to/paymenter

# Установи зависимости (если ещё не)
npm install

# Сборка для продакшена
npm run build

# ИЛИ dev-режим с hot reload
npm run dev
ℹ️

Файлы public/fastcloud/marketing.css и public/fastcloud/marketing.js — статические, Vite их не трогает. Они копируются как есть.

После сборки сбрось кеш шаблонов:

php artisan view:clear
php artisan cache:clear

4Настройка .env

Обязательные значения в .env:

# Название сайта (отображается в <title>)
APP_NAME="FastCloud"

# Реальный URL сайта (используется для asset(), route() и почтовых ссылок)
APP_URL=https://fast-cloud.uk

# Язык интерфейса
APP_LOCALE=ru
APP_FALLBACK_LOCALE=en

# Почта — нужна для сброса пароля и уведомлений
MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=noreply@fast-cloud.uk
MAIL_PASSWORD=your_password
MAIL_FROM_ADDRESS=noreply@fast-cloud.uk
MAIL_FROM_NAME="FastCloud"
⚠️

APP_URL должен совпадать с реальным доменом. Неправильный URL сломает favicon, ссылки в письмах и OAuth-редиректы.

5Активация темы в админке

  1. Войди в админ-панель

    Перейди на /admin и войди под администратором.

  2. Открой настройки внешнего вида

    Admin → Settings → Appearance.

  3. Выбери тему fastcloud

    В поле Theme выбери fastcloud и сохрани.

  4. Загрузи Logo Dark важно

    Поскольку тема всегда тёмная, нужен именно Logo Dark (поле «Dark Logo» или «Logo (Dark)»). Логотип для тёмного фона: белый или светлый, SVG с прозрачным фоном. Рекомендуемая высота: 32–40 px.

    Если Logo Dark не загружен, а Logo загружен — тема покажет его (темный логотип на темном фоне, может быть не виден).
    Если оба поля пусты — тема автоматически использует резервный SVG из public/images/logo-fastcloud.svg.

  5. Загрузи Favicon

    Поле Favicon. Рекомендуется SVG или ICO 32×32. Отображается во вкладках браузера.

  6. Настрой цвета темы

    В настройках темы (см. раздел «Настройки темы») задай цвета — тема использует их частично для accent-цвета.

Общие настройки — Settings → General

ПолеЗначениеГде используется в теме
Terms of Service URL https://fast-cloud.uk/offer Ссылка «Условия использования» в корзине при оформлении заказа. Если не задано — блок с согласием на TOS не отображается.

8Расширение CreditsPlus

CreditsPlus добавляет отображение баланса в навигацию для авторизованных пользователей и переопределяет компонент навигации когда пользователь залогинен.

Установка

  1. Файлы уже скопированы

    Если выполнил шаг 2, папка extensions/Others/CreditsPlus/ уже на месте.

  2. Включи расширение в админке

    Admin → Extensions → Others → CreditsPlus → Enable.

Как работает

Расширение регистрирует View Composer на components.navigation.index. Логика:

  • Пользователь не авторизован → используется навигация из темы (стандартно)
  • Пользователь авторизован → CreditsPlus подменяет путь к шаблону навигации на свой
  • В навигации появляется кликабельный баланс, ведущий на /account/credits
  • В мобильном меню — аватар + имя + выдвижная панель со ссылками
💡

Если нужно изменить навигацию (ссылки, логика), правки нужно вносить в два файла одновременно:
themes/fastcloud/views/components/navigation/index.blade.php (для незалогиненных)
extensions/Others/CreditsPlus/resources/views/components/navigation/index.blade.php (для залогиненных)

7PHP — Маршруты

⚠️

Файл routes/web.php в архиве — полная замена стандартного файла Paymenter. Если Paymenter уже установлен и в web.php есть кастомные маршруты — используй merge-подход: добавь только нужные строки вручную.

Если устанавливаешь с нуля — просто скопируй routes/web.php из архива.

Если мержишь вручную — добавь следующие строки в начало файла (после existing use-блоков) и в тело файла:

// Добавить в блок use-импортов:
use App\Livewire\Marketing;

// Добавить маршруты (после Route::get('/', Home::class)...):
Route::get('/pricing', Marketing\Pricing::class)->name('pricing');
Route::get('/locations', Marketing\Locations::class)->name('locations');
Route::get('/contacts', Marketing\Contacts::class)->name('contacts');
Route::get('/offer', Marketing\Offer::class)->name('offer');
Route::get('/privacy', Marketing\Privacy::class)->name('privacy');
Route::get('/sla', Marketing\Sla::class)->name('sla');

10Категории — Локации

В теме каждая top-level категория (без родителя) = одна локация. Она используется в двух местах: на странице тарифов (/pricing) — как кнопка выбора локации, и на странице локаций (/locations) — как карточка датацентра.

Создание категории

Admin → Categories → Create

ПолеПримерВажно
Name Германия Отображается как кнопка локации на странице тарифов и заголовок карточки на /locations
Slug germany Используется в URL: /products/checkout/germany/.... Только латиница, дефисы.
Parent — (пусто) Обязательно пусто. Дочерние категории тема не использует.
Sort 1, 2, 3… Порядок карточек на странице /locations. На /pricing сортировка по id.
Description JSON-объект (см. ниже) обязательно для /locations Без Description карточка на странице локаций не появится

Поле Description — JSON-структура обязательно

Страница /locations читает поле Description как JSON. Категория без Description или с невалидным JSON на странице локаций не отображается. 

{
  "region":       "europe",          // ключ региона (латиница, без пробелов)
  "region_label": "Европа",          // заголовок группы (отображается над карточками)
  "flag":         "🇩🇪",             // emoji-флаг страны
  "code":         "DE-FRA",          // код датацентра (отображается на карточке)
  "city":         "Франкфурт",       // город (отображается на карточке)
  "online":        true,              // true = зелёная метка «онлайн», false = красная «офлайн»
  "network":      "10 Gbps",         // сеть (отображается в спеках карточки)
  "storage":      "NVMe Gen4",       // хранилище
  "ddos":         "до 10 Gbps",      // Anti-DDoS
  "uptime":       "99.9%"            // аптайм SLA
}
⚠️

JSON должен быть валидным. Проверяй через jsonlint.com перед сохранением. Ошибка в JSON = карточка локации исчезает со страницы /locations без каких-либо сообщений об ошибке.

ℹ️

Категории с одинаковым region группируются под одним заголовком region_label. Например, все европейские датацентры можно объединить в группу "region": "europe".

11Продукты — Тарифы

Каждый продукт = один тарифный план (например, «Nano», «Micro», «Pro»).

ℹ️

Главная страница (/) показывает превью тарифов. Она берёт первую категорию по полю Sort и отображает её первые 3 продукта (по Sort). Убедись, что первая категория (с наименьшим Sort) содержит нужные продукты с заданными ценами на 1 месяц.

Основные поля

ПолеПримерПримечание
Name Pro Автоматически помечается как «популярный» (featured) средний по порядку сортировки тариф в категории. Привязки к названию нет.
Slug vps-pro Используется в URL checkout
Category Германия Привязывает к локации
Sort 1, 2, 3… Порядок отображения внутри локации (и на главной странице)

Stock 0 = неограничено При stock = 0 кнопка «В корзину» показывается

Установка порядка продуктов через Tinker dev

В форме редактирования продукта в админке поле Sort отсутствует. Порядок задаётся через php artisan tinker: 

# Посмотреть все продукты с текущим sort
App\Models\Product::orderBy('category_id')->orderBy('sort')
    ->get(['id', 'name', 'category_id', 'sort']);

# Установить sort конкретному продукту по slug
App\Models\Product::where('slug', 'vps-nano')->update(['sort' => 1]);

# Установить sort нескольким продуктам сразу
$order = ['vps-nano' => 1, 'vps-micro' => 2, 'vps-pro' => 3, 'vps-ultra' => 4];
foreach ($order as $slug => $sort) {
    App\Models\Product::where('slug', $slug)->update(['sort' => $sort]);
}
💡

Главная страница берёт первые 3 продукта по sort из первой категории. Убедись, что у продуктов этой категории проставлены sort = 1, 2, 3.

Product Settings — характеристики сервера

На странице конфигурации и в карточке тарифа отображаются характеристики. Они задаются через Product Settings (не Config Options). Ключи строго фиксированы:

Ключ (key)Пример значенияГде отображается
cores4«4 vCPU» на карточке и в конфигураторе
memory8«8 GB RAM»
disk80«80 GB NVMe»
trafficБезлимит«Безлимит трафик»
⚠️

Ключи чувствительны к регистру. Только строчные: cores, memory, disk, traffic. Если ключ не найден — показывается «—».

13Планы и цены

Каждый продукт может иметь несколько планов (периодов оплаты). Тема распознаёт следующие периоды:

Billing PeriodBilling UnitКлюч в темеОтображение
1monthmonthly1 месяц
3monthquarterly3 месяца
6monthbiannual6 месяцев
12monthannual12 месяцев
⚠️

Другие периоды (например, 2 мес, 24 мес) тема игнорирует — план не попадёт на страницу тарифов.

Тарифная сетка FastCloud

Базовые цены в рублях. Скидки применяются к итоговой сумме за период.

Тариф 1 месяц 3 месяца (−5%) 6 месяцев (−10%) 12 месяцев (−20%)
Nano600 ₽1 710 ₽3 240 ₽5 760 ₽
Micro1 500 ₽4 275 ₽8 100 ₽14 400 ₽
Standard ⭐3 000 ₽8 550 ₽16 200 ₽28 800 ₽
Plus6 000 ₽17 100 ₽32 400 ₽57 600 ₽
Ultra12 000 ₽34 200 ₽64 800 ₽115 200 ₽
💡

Скидка считается автоматически: тема сравнивает цену многомесячного плана с ценой месячного и показывает бейдж −N%. Цифры выше — итоговые суммы за весь период.

Скидки на длинные периоды

Скидка считается автоматически: тема берёт цену 1-месячного плана и сравнивает с ценой за месяц при более длинном периоде. Если выходит дешевле — показывается бейдж −N%. Для этого обязательно должен существовать план на 1 месяц.

Настройка цен

  1. Создай план

    Product → Plans → Add Plan. Укажи Billing Period и Unit.

  2. Добавь цену

    В плане → Prices → Add Price. Выбери валюту RUB, укажи цену.

  3. Повтори для каждого периода

    1 мес, 3 мес, 6 мес, 12 мес.

15Задачи программисту dev

Следующие вещи выходят за рамки темы и требуют правок в PHP-коде Paymenter:

1. Заголовки страниц (SEO)

Маркетинговые страницы (/pricing, /locations и др.) не передают $title в лейаут — все страницы показывают просто «FastCloud». Нужно добавить атрибут #[Title] к соответствующим Livewire-компонентам: 

// app/Livewire/Marketing/Pricing.php
use Livewire\Attributes\Title;

#[Title('Тарифы')]
class Pricing extends Component { ... }

Аналогично для: Locations, Contacts, Home, Offer, Privacy, Sla.

2. OG-теги для соцсетей

Добавить $description и $image слоты в лейаут каждой маркетинговой страницы для корректного превью в соцсетях. Лейаут layouts/app.blade.php уже поддерживает эти слоты.

3. «Популярный» тариф

Сейчас featured-продукт определяется хардкодом в app/Livewire/Marketing/Pricing.php: 

// Средний по sort индекс в категории:
'featured' => $_prodIdx === $middleIndex,

Рекомендуется заменить на поле в Product Settings (например, ключ featured = 1), или использовать отдельное поле продукта.

4. Уведомления об ошибках на русском

Некоторые сообщения Paymenter передаются хардкодом на английском (например, в app/Livewire/Cart.php). В теме реализован JS-словарь переводов, но при добавлении новых уведомлений нужно пополнять словарь в themes/fastcloud/views/components/notification.blade.php.

5. Сервер приложений

Для продакшена рекомендуется настроить supervisor для очереди задач: 

php artisan queue:work --daemon
